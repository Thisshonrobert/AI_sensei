# Next.js application entry

Routes include the review-first dashboard, `/review`, reference lists/details, read-only vocabulary/kanji `/[kind]/flashcards` and exact source records. `/api/review` owns same-origin localhost review, budget and attention mutations. Retrieval stays on Node; private PDFs/raw JSON are never served. Scheduled answers/backs remain gated by explicit introduction or committed recall; reference browsing has no scheduling action. See the Phase 3 handoff and frontend follow-up for verification and limits.
