# Next.js application entry

Phase-1 read-only Next.js routes: `/`, `/vocabulary`, `/kanji`, `/grammar`, `/<kind>/<id>`, `/sources` and `/sources/<id>`. Database retrieval stays on the Node server. Source links select the exact citation, including historical evidence; private PDFs and raw JSON are not served. Empty/error/loading states exist. No learner or scheduler mutations are implemented. Choose one mutation convention per feature when phase 2 begins.
