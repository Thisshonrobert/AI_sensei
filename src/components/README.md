# Shared UI

`entry-navigation.tsx` supplies accessible previous/next chevrons on vocabulary, kanji and grammar detail pages. Adjacency uses bounded catalog-order queries in `catalog.ts`.

`reference.tsx` supplies collapsed evidence and stored-record rendering; `item-facts.tsx` supplies detail facts. `browse-flashcard.tsx` supports card-click/keyboard flipping and side-chevron navigation; `flashcard-facts.tsx` keeps browse backs compact. `vocabulary-components.tsx` shows approved source box meanings or existing canonical glyph matches. `example-meaning.ts` connects unique approved word/reading supplements without rewriting book content. `kanji-mnemonic.tsx` presents stored components and complete text or explicit excerpts. `review.tsx` retains study → recall → reveal → assess → rate. `study-content.tsx` supplies approved examples/comparisons; `daily-budget.tsx` edits the block budget. `dictionary.tsx` opens explicit selected/copied-text lookup with inline fallback and keeps attention flags separate. The interactive reader remains deferred to Phase 5.
