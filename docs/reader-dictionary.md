# Local reader dictionary

Authority: Master Plan §20, the reader amendments and the learner's explicit 9 October 2026 authorization. This is a bounded Phase 5 study-reader extension. It changes neither generation/publication gates nor timed-reading aids or canonical/learner/scheduler state.

The study reader prepares reference spans on passage retrieval using the already approved server-side kuromoji/IPADIC analyzer and an English JMdict index. Approved revision-bound annotations take precedence; overlapping retained annotations use longest span, then vocabulary before kanji for identical spans. Partial-character annotations that cut a lexical token are omitted from the reader rather than splitting a compound or hiding its remaining kanji; retained content and publication diagnostics stay unchanged. Dictionary-only words never receive an Item identity by spelling/lemma similarity. Existing approved-vocabulary sentence saving retains the exact revision, target, ownership and deduplication checks.

Whole compounds use tokenizer boundaries and exact dictionary forms. Inflected verbs/adjectives retain their analyzer lemma and attached auxiliaries; suru constructions retain their whole surface. Ordinary particles are not folded into an unrelated dictionary expression. Offset reconciliation uses passage text and UTF-16 boundaries, including supplementary characters. Unknown lexical runs may remain unsegmented: tokenization is not proof of a correct word boundary. No individual-kanji readings are synthesized.

Dictionary meanings/POS/readings are candidates. Spelling/reading and sense restrictions, no-kanji readings, inherited POS and dictionary notes are preserved in the English projection. General senses are not automatically selected by context. Inflected surface readings use whole lexical token readings from kuromoji, explicitly labelled as analyzer candidates; all reference readings remain unverified even after the passage is approved. Hover displays the single contextual reading (preferring analyzer tokenization, falling back to primary dictionary candidate), while the panel lists candidates and applicable readings. A lookup reads at most 16 indexed entry records, displays at most eight entries/eight senses per entry, and discloses truncation. Missing entries/readings, installation failure and overdue updates remain visible; explicit editable Takoboto lookup continues to work.

The passage has one keyboard tab stop; Left/Right and Home/End move focus between spans, Enter/Space opens the shared popup, and Escape/Close restore focus. The word selector remains available. Off hides ruby; All displays reviewed annotation readings while dictionary/analyzer candidates still reveal only on request. Reference lookups run when loading the passage, with no hover/click network request or AI. Unmatched words keep the existing draft/import and human review path; there is no independent saved-word model.

## Installation, licence and updating

Run from the repository root with Node (no new package or migration):

```powershell
rtk proxy node scripts/update-reader-dictionary.mjs
```

The script downloads the [official English JMdict file](https://www.edrdg.org/pub/Nihongo/JMdict_e.gz) and [EDRDG licence](https://www.edrdg.org/edrdg/licence.html). A bounded format-specific JMdict projection rejects external XML entities and unresolved entities; it does not resolve external DTDs. It produces a UTF-8 JSON-lines file plus an exact-form byte-offset index. Only the index is held in memory; dictionary reads retrieve bounded explicit records. These files are not SQL/application records and never enter `public/`.

Storage is `private-data/dictionary/current.json` plus immutable source-hash/unique-edition directories containing `entries.jsonl`, `index.json`, `metadata.json`, `ATTRIBUTION.txt` and a copy of `EDRDG-licence.html`. A new edition is fully written in a separate pending directory and renamed before the pointer is replaced; repeated identical downloads cannot overwrite the active edition. Failed downloads/builds/pointer publication leave the last pointer intact. Previous/pending editions remain ignored; any later cleanup must preserve the current edition and active readers. Application restart is unnecessary for a successful refresh; each passage reload checks the current edition. No background automation has been installed.

The [official project documentation](https://www.edrdg.org/jmdict/j_jmdict.html) identifies JMdict as a dictionary generated daily. The [EDRDG general licence](https://www.edrdg.org/edrdg/licence.html) places its Japanese/English data under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), requires acknowledgement/source and documentation/licence access, and requires a regular update procedure (at least monthly is its web-server example). Copyright remains with James William Breen and EDRDG; they do not endorse this app. Distributed adapted dictionary data must retain a compatible ShareAlike licence; that does not impose an open-source licence on independent application software. The reader displays attribution and project/licence links on the screen, and the local edition retains notices and the official licence copy.

**Refresh at least once each month**, and before use if the reader says the update is overdue. The screen shows installation date; metadata also records source Last-Modified, SHA-256, entry count and transformation. The updater requires internet; reading an installed dictionary and stored reviews do not. Deployment/packaging must separately include this ignored dictionary storage or run installation locally; Git and Next.js application output do not bundle it.

The 10 October 2026 installation contains 218,880 entries, sourced from the official file with Last-Modified 9 October 2026. That count is an installation check, not coverage or contextual-language verification. JMdict/IPADIC can omit words, split compounds, offer obsolete/rare alternatives, or misanalyse names and constructions. Synthetic tests verify structural behavior and state boundaries; human Japanese review remains necessary.
